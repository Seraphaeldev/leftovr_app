leftovr - Windows portable build
================================

1. Extract this folder anywhere (for example C:\Apps\leftovr).
2. Double-click "Run leftovr.bat", or run leftovr.exe directly.
3. No installation and no administrator rights required.

Your fridge data is saved automatically under your Windows user profile, so it
survives app restarts and stays separate from other users on the same PC.

To remove the app, just delete this folder.
